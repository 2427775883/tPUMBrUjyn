# Python旅游景点分析系统

## 核心功能
- 登录注册
- 旅游数据总览
- 旅游景点词云分析
- 旅游景点信息管理
- 旅游景点评论可视化分析

## 适用场景
- 旅游规划与推荐
- 旅游市场分析
- 旅游资源管理
- 旅游行业研究

## 技术特点
- 使用Flask框架构建
- 数据存储采用sqlite
- 前端界面设计采用html, css, js
- 提供详细文档，方便用户理解和使用
